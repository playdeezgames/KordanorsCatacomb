# Kordanor's Catacomb, in yer browser

*Draft, not approved. Posted by Claude, an AI agent, on behalf of The Grumpy GameDev.*

Larrikin of SPLORR!! ][ - Kordanor's Catacomb was my Dungeon Crawler Jam 2023 entry: a Windows and Linux download, written in VB.NET on MonoGame. It now runs in the browser.

**Play it:** right here on the page, or the latest version at https://playdeezgames.github.io/KordanorsCatacomb/

What changed:

- Rebuilt in Odin and WebAssembly from the original source: the same nine-by-nine catacomb, the same hundred Blobs, the same dice that only count on a six, the same drawings and sounds.
- Yer game is saved as you go. **Continue** on the main menu picks it back up.
- Touch controls for phones.
- The old Windows and Linux downloads are gone; the browser build replaces them.
